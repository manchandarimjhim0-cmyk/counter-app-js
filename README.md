# 🚀 Counter App

A simple and responsive Counter App built using **HTML, CSS, and JavaScript**. This project demonstrates DOM manipulation, event handling, reusable functions, and interactive button animations.

## 🌐 Live Demo

🔗 https://manchandarimjhim0-cmyk.github.io/counter-app-js/
## ✨ Features

- ➕ Increase Counter
- ➖ Decrease Counter
- 🔄 Reset Counter
- 🎨 Button color animation on click
- ⚡ Smooth button click effect
- 📱 Responsive and clean UI
- 💻 Built with Vanilla JavaScript

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/manchandarimjhim0-cmyk/counter-app-js.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
